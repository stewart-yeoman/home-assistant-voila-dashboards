# home-assistant-voila-dashboards
Jupyter notebooks with ipywidgets that can be used in HomeAssistant with Voila

If you have the HomeAssistant Jupyter Add-on/App installed, you can use the Voila feature of Jupyter to display notebooks as dashboards inside HomeAssistant.
